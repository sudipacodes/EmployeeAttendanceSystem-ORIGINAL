Employee Attendance API is running

This project's UI is now an Angular app in /ClientApp, served separately from this API.

  • Development: cd ClientApp && npm install && npm start, then open http://localhost:4200.
  • Production: cd ClientApp && npm run build, then copy the contents of ClientApp/dist/attendance-ledger-client/ into this wwwroot folder (replacing this file) so the API can serve the built Angular app directly.

API documentation: /swagger (Development environment only).
